The funniest one-line warning label for a time machine — 120 characters or fewer. It reads like a genuine safety notice, turns a real hazard of time travel (the grandfather paradox) into the joke by treating it as a refund-policy matter, and saves the surprise for the last few words.

## The label

> WARNING: This time machine will not refund births you prevent. Please vanish responsibly.

## Run it

```sh
python3 main.py
```

This prints the label and writes it to `/output/entry.txt` (one line, 89 characters, UTF-8, no trailing newline).
